The outline chain

The outline_chain property is central to each base. The outline_link property should be able to stand alone and (potentially) constitute a single meeting/session with a disciple. The outline_sublink is a node hierarchically beneath this and often will include references to other base properties/fields (e.g. it is reasonable that a mind_movie in the mind_movies array could itself constitute the majority or all of an outline_sublink).

It is also conceivable that an outline_sublink could have multiple base property/field references (e.g. an outline_sublink could have multiple base_prop_refs: concept_entry, scripture, scripture, image, image, video, hand_gisture).
